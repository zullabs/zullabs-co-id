Cara Pasang & Coba di Laptop Kamu

01

Pastikan Python 3.10+ & Software Target Sudah Terpasang

CLI-Anything mengendalikan mesin asli aplikasi di laptopmu (bukan tiruan cloud), jadi pastikan python --version minimal 3.10 dan aplikasi target (misal Blender / GIMP / LibreOffice) sudah terinstall.

02

Install CLI-Hub Lewat Terminal

Jalankan perintah pip berikut untuk memasang manajer paket komunitas CLI-Anything:

03

Pasang Harness Aplikasi Pilihanmu atau Buat Sendiri

Gunakan cli-hub install <nama-app> untuk pasang instan, atau pakai slash command /cli-anything <path-atau-repo> di agent coding kamu untuk membuat CLI baru otomatis.

Salin perintah cepat (Terminal / PowerShell) 
# 1. Pasang CLI-Hub
pip install cli-anything-hub

# 2. Cari dan pasang harness aplikasi yang tersedia
cli-hub search
cli-hub install <nama-app>

# 3. Atau clone repo lengkap untuk plugin Claude Code / Cursor / Pi / OpenCode
git clone https://github.com/HKUDS/CLI-Anything.git
Catatan Jujur Engineer

Yang Perlu Kamu Siapkan Sebelum Mencoba

  • Bukan sihir tanpa aplikasi: Software aslinya (seperti Blender, GIMP, atau LibreOffice) tetap harus terpasang di laptopmu — CLI-Anything menjadi jembatan terstruktur antara AI agent dan backend asli aplikasi tersebut.
  • Butuh AI Coding Agent: Paling terasa manfaatnya kalau kamu sudah memakai agent seperti Claude Code, Cursor, OpenClaw, Pi, atau OpenCode.
  • 100% Open-Source: Seluruh kode CLI-Anything bebas biaya dengan lisensi Apache-2.0 (biaya hanya berasal dari model/API AI agent yang kamu pakai sendiri).
