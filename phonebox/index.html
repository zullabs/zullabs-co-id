Cara Pasang di Laptop & HP Android Lama

01

Install Desktop Agent (1 Baris Perintah)

Buka PowerShell biasa di Windows (atau Terminal di Linux/macOS), lalu jalankan skrip setup resmi di bawah. Setelah selesai, halaman pengaturan terbuka otomatis di http://127.0.0.1:8765.

02

Hubungkan HP Android 5+ (USB atau Wi-Fi)

Via USB: Aktifkan Developer Options → USB Debugging, colok kabel data, lalu biarkan installer memasang aplikasi Android-nya otomatis.
Via Wi-Fi: Pasang APK dari GitHub Releases, aktifkan mode Wi-Fi di pengaturan 127.0.0.1:8765, lalu scan QR pairing.

03

Pilih Template atau Atur Sendiri (Atau Suruh AI Agent)

Buka menu Pages di http://127.0.0.1:8765, pilih dari 30 template siap pakai, seret widget favoritmu, klik Save. Pengguna Claude Code/Codex/OpenCode juga bisa mengaktifkan notifikasi & tombol Allow/Deny langsung di HP.

Salin perintah cepat (Windows PowerShell) 
irm https://raw.githubusercontent.com/ersinkoc/phonebox/main/setup.ps1 | iex
Salin perintah cepat (Linux / macOS) 
curl -fsSL https://raw.githubusercontent.com/ersinkoc/phonebox/main/setup.sh | bash

Yang Wajib Kamu Tahu Sebelum Mencoba

  • Khusus Android 5+ (disarankan 6+): Aplikasi companion iOS masih eksperimental (harus kompilasi sendiri via Xcode) dan belum punya fitur panel penuh seperti Android.
  • Bukan dari Play Store & SmartScreen Windows: APK resmi hanya ada di GitHub Releases. Agent Windows juga belum bertanda tangan sertifikat rilis penuh sehingga Windows SmartScreen/antivirus mungkin memunculkan peringatan — selalu cek dulu isi setup.ps1 sebelum jalan.
  • Jaga Kesehatan Baterai HP Lama: Kalau HP dicolok USB terus-menerus di meja, aktifkan fitur Protect Battery (batas cas 80%) jika tersedia atau gunakan pairing Wi-Fi + cas berkala agar baterai tidak cepat kembung.
