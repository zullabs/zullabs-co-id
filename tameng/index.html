Langkah Demi Langkah

Cara Coba Gratis di Google Colab (Tanpa Laptop Mahal)

01

Buka Notebook Colab #1 dan Login Google

Klik kartu Colab Encoder Attack (Img2Img) di atas. Setelah terbuka, klik menu File → Save a copy in Drive supaya kamu punya salinan pribadi yang bisa diedit.

02

Aktifkan GPU Gratis (T4)

Di menu atas Google Colab, pilih Runtime → Change runtime type → Hardware accelerator: T4 GPU lalu klik Save. Tanpa GPU, proses 200 iterasi akan sangat lambat.

03

Jalankan Sel Instalasi dari Atas ke Bawah

Klik ikon tombol putar (▶) pada tiap blok kode secara berurutan. Tunggu pustaka diffusers, torch, dan model Stable Diffusion selesai terunduh di server Colab.

04

Siapkan Token Hugging Face (Jika Diminta)

Beberapa versi model meminta login Hugging Face. Buat akun gratis di huggingface.co/settings/tokens, buat token tipe Read, lalu tempel saat diminta.

05

Uji dengan Foto Sampel & Bandingkan Hasilnya

Jalankan dulu dengan foto bawaan notebook untuk melihat hasilnya, lalu coba unggah foto uji sendiri. Perhatikan bagaimana hasil edit AI pada foto ber-tameng menjadi rusak/tidak wajar dibanding foto polos.

Opsional · Jalankan di PC/Laptop Lokal (Butuh GPU NVIDIA) 
git clone https://github.com/MadryLab/photoguard.git
cd photoguard
conda create -n photoguard python=3.10 -y
conda activate photoguard
pip install -r requirements.txt
huggingface-cli login
cd demo && python app.py
Catatan Jujur Engineer

Hal yang Wajib Kamu Tahu Sebelum Mengandalkannya

  • Spesifik ke model target: Implementasi asli MIT ini dibuat untuk menargetkan pipeline Stable Diffusion. Model AI editor komersial generasi lebih baru punya arsitektur encoder berbeda sehingga efek perlindungannya bisa berkurang.
  • Sensitif terhadap kompresi ekstrem: Jika foto di-crop besar-besaran, di-screenshot berulang, atau dikompresi berat oleh media sosial, pergeseran piksel tipis ±1 bisa ikut tergerus.
  • Nilai utamanya: Anggap PhotoGuard sebagai fondasi belajar & eksperimen keamanan AI (adversarial machine learning) — bukan jaminan kebal 100%, tapi titik awal nyata untuk memahami bagaimana peneliti melawan penyalahgunaan deepfake.
